## Digital Economy and Data Privacy Laws

### Project Description
This is an exploratory data analysis to assess the question **to what extent is a country's digital economy associated with the strictness of its data privacy laws?**

As technology becomes increasingly prevalent in our daily lives, it is imperative sufficient legislation is enforced to protect user data and privacy. The research question will be broken into two components: digital economy and data privacy laws. The digital economy will be measured through internet usage rate per population. The data privacy laws will be evaluated based on the existence of legislation and its enforcement.

### Data Sources
1. UNCTAD Global Cyberlaw Tracker
  - https://unctad.org/topic/ecommerce-and-digital-economy/ecommerce-law-reform/summary-adoption-e-commerce-legislation-worldwide
2. Comparitech Privacy Protection and the State of Surveillance
  - https://www.comparitech.com/blog/vpn-privacy/surveillance-states/
3. Our World in Data
  - https://ourworldindata.org/grapher/number-of-internet-users
4. ISO Code Data
  - https://github.com/lukes/ISO-3166-Countries-with-Regional-Codes/blob/master/all/all.csv
5. World Bank Group Population Data
  - https://data.worldbank.org/indicator/SP.POP.TOTL

### Project Structure
*Final Project.py* includes the code for this exploratory data analysis. It includes exporting, cleaning, and manipulating the data sources. It also includes the code to generate tables and visualizations that guided the final report.

*datasets* includes the data sources utilized for this data analysis. They are formatted in xlsx or csv files exported from the links above.

*results* includes tables generated from this data analysis. It has a sub-folder *visualizations* that includes png files of visualizations generated from this data analysis.
