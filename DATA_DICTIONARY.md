| Variable | Description |
|---|---|
| country | Country name |
| constitutional_protection | Comparitech score for constitutional privacy protections |
| statutory_protection | Comparitech score for statutory (legal) privacy protections |
| privacy_enforcement | Comparitech score for how well privacy rules are enforced |
| identity_cards_and_biometrics | Comparitech score for rules on ID cards and biometric data |
| data_sharing | Comparitech score for rules on sharing personal data |
| visual_surveillance | Comparitech score for rules on camera and visual surveillance |
| communication_interception | Comparitech score for rules on intercepting communications |
| workplace_monitoring | Comparitech score for rules on employee monitoring |
| government_access_to_data | Comparitech score for government access to personal data |
| communication_data_retention | Comparitech score for retention of communications data |
| surveillance_medical_financial_movement | Comparitech score for surveillance of medical, financial, and movement data |
| border_and_trans_border_issues | Comparitech score for border and cross-border data issues |
| leadership | Comparitech score for a country's leadership on privacy issues |
| democratic_safeguards | Comparitech score for democratic safeguards for privacy |
| total | Overall Comparitech privacy score across all categories |
| score_card | Comparitech's summary rating or category label for the country's overall privacy score |
| iso_code | ISO alpha-3 country code |
| numeric_code | ISO numeric country code |
| electronic_transactions | UNCTAD legislation status for electronic transactions |
| consumer_protection | UNCTAD legislation status for online consumer protection |
| privacy_and_data_protection | UNCTAD legislation status for privacy and data protection |
| cybercrime | UNCTAD legislation status for cybercrime |
| indirect_taxation | UNCTAD legislation status for indirect taxation of digital transactions |
| africa | Indicator of whether the country is in Africa (1 = yes, 0 = no) |
| latin_america_and_caribbean | Indicator of whether the country is in Latin America and the Caribbean (1 = yes, 0 = no) |
| asia_and_oceania | Indicator of whether the country is in Asia and Oceania  (1 = yes, 0 = no)|
| developing_countries | Indicator of whether the country is classified as developing (1 = yes, 0 = no) |
| developed_countries | Indicator of whether the country is classified as developed (1 = yes, 0 = no) |
| least_developed_countries | Indicator of whether the country is classified as least developed (1 = yes, 0 = no) |
| landlocked_developing_countries | Indicator of whether the country is a landlocked developing country (1 = yes, 0 = no) |
| small_island_developing_states | Indicator of whether the country is a small island developing state (1 = yes, 0 = no) |
| europe | Indicator of whether the country is in Europe (1 = yes, 0 = no) |
| northern_america | Indicator of whether the country is in Northern America (1 = yes, 0 = no) |
| internet_users | Number of people using the internet in 2024 |
| 2024 | Total population in 2024 from the World Bank Group |
| population | Copy of the 2024 column converted to numeric |
| internet_pct | Percentage of the population using the internet |
| region | Region of the country |
| laws_count | Number of the five UNCTAD laws a country has (0-5) |
| law_group | Whether a country has all 5 laws or is missing 1 or more |
| privacy_score | Comparitech total score rescaled to 0-100 |
| law_score | Percentage of the five UNCTAD laws a country rescaled to 0-100 |
| users_score | Internet percentage rescaled to 0-100 |
| digital_score | Average of users_score and law_score rescaled to 0-100 |
| joint_score | Average of privacy_score and digital_score  rescaled to 0-100 |
